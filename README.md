Landing page portfolio cá nhân hiện đại dành cho **Nguyễn Thế Bảo (Bảo)**, sinh viên năm 2 ngành **Kinh tế số (Digital Economy)** tại **Đại học Đại Nam**, chuyên sâu về sáng tạo mô hình 3D, kết xuất hình ảnh và vận hành tối ưu hóa gian hàng thương mại điện tử quốc tế (TikTok Shop US, Shopee, Etsy, ShopBase).

---

## ⚡ Công nghệ sử dụng (Tech Stack)

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com/)
- **Animation**: [Framer Motion 12](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: [Google Font Kanit](https://fonts.google.com/specimen/Kanit) (weights 300 - 900)
- **Theme**: Dark Luxury Theme (`#0C0C0C`) kết hợp hiệu ứng gradient ánh kim `.hero-heading`
